Automated Reporting (Demo)

This example shows a tiny automated reporting workflow that reads demo sales CSV data and writes a simple HTML report.

Files:
- `generate_report.py` — small Python script to produce `report.html` from `data/sales.csv`.
- `data/sales.csv` — synthetic transactional sales data.

How to run:
1. Ensure you have Python 3 installed.
2. Run `python generate_report.py` from the `examples/automated-reporting` folder.
3. Open `report.html` in your browser.
