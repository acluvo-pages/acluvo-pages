# Acluvo Version 1.1 Website

A lightweight, one-page static website designed for GitHub Pages.

## Files
- `index.html` — page structure and website copy
- `styles.css` — responsive brand styling
- `script.js` — mobile navigation and subtle scroll animations

## Preview locally
Open `index.html` directly in a browser, or run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish on GitHub Pages
1. Create a GitHub repository, for example `acluvo-site`.
2. Upload the files in this folder to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose your main branch and `/ (root)`.
6. Save.
7. In **Settings → Pages → Custom domain**, enter your secured domain.
8. Add the DNS records GitHub provides at your domain registrar.

## Before launch
Review or update:
- `hello@acluvo.com`
- Pricing and service wording
- Footer legal name after you form `Acluvo LLC`
- Add your LinkedIn URL when ready
- Replace the starter inline SVG mark with your final production logo SVG when you export it
