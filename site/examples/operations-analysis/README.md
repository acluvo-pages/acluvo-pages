Operations Analysis (Demo)

This example contains a simple client-side operations analysis demo that lets you filter and inspect synthetic operational events.

Files:
- `index.html` — interactive table and simple visual summary using plain JS.
- `data/ops.json` — synthetic operations events (timestamps, services, durations, statuses).

How to run:
1. Open `examples/operations-analysis/index.html` in your browser.
2. Use the on-page filters to explore the dataset.
