Business KPI Dashboard (Demo)

This is a lightweight demo of an Acluvo-style Business KPI Dashboard using synthetic data.

Files:
- `index.html` — simple dashboard using Chart.js (CDN) and local `data/kpis.json`.
- `data/kpis.json` — synthetic KPI time series (monthly).

How to run:
1. Open `examples/business-kpi-dashboard/index.html` in your browser.
2. The page loads `data/kpis.json` and renders charts.

Notes: This demo uses CDN-hosted Chart.js so no install is required.
